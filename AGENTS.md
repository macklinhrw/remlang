# Working in this repo

- Use pnpm 10 (pinned in `package.json#packageManager`) and Node 24. pnpm 11
  ignores `package.json#pnpm`, which drops the `patches/`.
- Before finishing a change, run `pnpm typecheck && pnpm lint && pnpm test`.
  `pnpm test` runs the `node:test` suites with tsx, then `bun test` in `backend/`.
- Dictionary data is downloaded by `pnpm fetch:resources` (pinned and
  checksummed in `scripts/data/sources.ts`) and built by `pnpm seed`. Never commit
  anything under `assets/resources/`, `assets/database.db` or `dist-data/`.
- Schema changes go through Drizzle migrations in `drizzle/`; tests and the seed
  apply the same migrations, so don't hand-write `CREATE TABLE` in tests (use
  `lib/testing/migratedTestDb.ts`).
- `android/` and `ios/` are generated by `npx expo prebuild`. Native build
  settings belong in `app.config.ts` or `plugins/`.
- Design specs for larger features go in `docs/design/`.
- Never commit `.env` files, `assets/decklists/` or any textbook-derived content.
